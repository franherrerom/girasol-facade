    Export STL for printing
    
      
      
    
      
      
      
      The file is in millimeters with Z up, which is what slicers expect. Only your design is exported, not the context, figure or ground. The thin-part check measures each part's overall size, so a thin wall inside a bigger shape can slip past it: always check the file in your slicer.
      
      
        
        
      
    
      
        

  
  
    
      
      
      Export OBJ for Rhino
      
      
      
      Real size, Z up. In Rhino, set your document to the same units first (type Units in the command line), then File > Import with "Map OBJ Y to Rhino Z" unchecked. The unit is in the file name so you don't forget.
